# 🏰 程程学习工作台

> **一个让学习像玩游戏一样上瘾的家庭学习平台** —— 基于《奇妙萌可》主题，专为学龄前及小学低年级孩子设计。

---

## 👧 给小朋友：这是你的魔法城堡

你有一座属于自己的**萌可城堡**🏰！城堡里住着你用学习召唤来的萌可小伙伴——爱心萌可、勇气萌可、唱唱萌可……每个萌可都有自己的性格和技能。

### 📝 每天要做三件事

1. **做今日一练** 🎯 —— 语文、数学、英语各5~12道题，难度会随连续天数逐渐提升
2. **去学习** 📚 —— 学拼音、认字、背古诗、练口算、做应用题，每完成一个模块就拿到学习星 ⭐
3. **玩游戏** 🎮 —— 拼音消消乐、凑十法、古诗填空……得分就是积分！

### 🧸 收集萌可

你可以在「萌可图鉴」里看到所有收集到的萌可，它们住在城堡的不同区域。首页还有**萌可旋转木马**🎠，展示你已收集的萌可朋友。

### 📖 萌可故事

读萌可的故事，回答小测验，还能**捕捉萌可**回到你的城堡！每个故事章节都藏着新萌可，集齐它们吧！

### 🏰 城堡经营

城堡里的萌可会每天送你**星星币** ⭐，连续打卡天数越多，城堡繁荣度越高，萌可送的币也越多！

用星星币可以去**萌可商店**换：
- 🏰 **城堡皮肤**（6款：梦幻/星空/糖果/海洋/花园/魔法，各有专属动态装饰）
- 🖼️ **头像框**（6款：金色/银光/彩虹/星光/爱心/皇冠）
- ⭐ **勋章**（2款：星星/爱心，在头像右上角显示）
- 🏆 虚拟奖状、🎀 萌可装扮

### ⚠️ 不打卡会怎样？

如果你有天没完成三科打卡，捣蛋萌可（闹闹、迷糊、淘气）会溜进城堡捣乱！连续多天不打卡，它们会越来越多。

别担心！你可以在**魔法商店**买道具：
- 🧴 **魔法喷雾**（5阳光）—— 把捣蛋萌可捉回去
- 🛡️ **护盾**（10阳光）—— 帮萌可挡住一次捣蛋
- 🧊 **冰冻徽章**（8阳光）—— 保护连胜不中断

### ⏳ 时光沙漏

如果偶尔忘了打卡，可以向爸爸妈妈申请一个**时光沙漏**⏳，回到昨天补打卡。爸爸妈妈审批通过后就能使用。

### 📊 成长记录

在「成长记录」页，你能看到：
- 📅 **打卡日历** —— 像 GitHub 贡献图一样，绿绿的表示坚持了
- 📈 **积分趋势** —— 最近 7 天的积分变化
- 🌳 **成长树** —— 记录你每次的学习和收获

### 🏆 成就徽章

每次学习都能解锁成就：
- 🧸 萌可收藏家 —— 收集更多萌可
- 📅 坚持打卡 —— 连续天数越多越厉害
- 🀄 拼音小将 / ✍️ 识字小能手 / 📜 小诗人 / 🔢 数学小星 / 🗣️ 表达小明星

## 👨‍👩‍👧 给爸爸妈妈：轻松管理孩子的学习

### 🔑 账号体系

- **家长账号**（`parent`）：管理所有孩子、发布任务、审批兑换、查看看板
- **孩子账号**（`cara`）：学习、玩游戏、收集萌可、向家长申请道具

首次启动默认账号：家长 `parent` / `12345678`，孩子 `cara` / `0000`（建议首次登录后修改密码）

### 📊 家长看板

在「爸爸妈妈看板」页面，你可以：
- 👀 查看每个孩子的**今日学情**（哪科做了、哪科没做）
- 📈 查看**本周积分趋势图**
- 👨‍👩‍👧 **多娃对比**：如果有多个孩子，自动并列显示积分、萌可数、连胜天数
- 🏰 管理**萌可城堡**：查看城堡状态，给城堡补充资源
- 🎁 审批孩子的**星星币兑换**请求

### 📋 发布任务

在「任务」页面，你可以：
- 发布学习任务（背一首古诗、做一页口算、读一篇课文……）
- 设置任务积分奖励
- 孩子完成后自动发放积分

### ⏳ 时光沙漏审批

孩子请求使用时光沙漏后，你可以在看板或弹窗中看到审批列表。通过后孩子可以回到昨天补打卡。

### 💾 数据备份与导出

在「设置」页面：
- ⬇️ **导出数据** —— 下载 JSON 备份文件
- ⬆️ **导入数据** —— 从备份文件恢复（会覆盖当前数据）
- 📊 **导出 CSV 学习数据** —— 下载学习记录，可在 Excel 中打开分析
- 🔄 支持修改密码

## 🏗️ 技术栈

| 层面 | 技术 |
|------|------|
| 前端 | Next.js 14 (App Router) + React 18 + TypeScript (strict) + Tailwind CSS |
| 数据库 | Turso (LibSQL) / 本地 SQLite（首次启动自动建库，WAL 模式） |
| 认证 | 自定义 session cookie（bcrypt 哈希，家长/孩子双角色，7天过期） |
| TTS | 三层策略：Web Speech → 宽松 Web Speech → Python edge-tts 持久化进程 |
| 测试 | Vitest（125+ 测试用例） |
| 部署 | GitHub Actions → Docker 多阶段构建（~550MB）→ GHCR；支持飞牛 NAS / Vercel |

## 📲 装到主屏（像 App 一样用）

本工作台是 **PWA（渐进式 Web 应用）**：装到主屏后全屏打开，还能离线看已缓存内容。

**安卓**：打开站点 → ⋮ 菜单 →「安装应用」/「添加到主屏幕」

**iPhone / iPad**：Safari → 分享按钮（⬆） →「添加到主屏幕」

> 联网时打开过的页面会被缓存，断网后仍能复习；实时数据需联网同步。

## 🚀 快速开始

```bash
# 1. 克隆仓库
git clone https://github.com/JE668/chengcheng-learning-workbench.git
cd chengcheng-learning-workbench

# 2. 安装依赖
pnpm install

# 3. 启动开发服务器
pnpm dev

# 4. 打开浏览器访问
# http://localhost:3000
```

## 🐳 Docker 部署

```bash
# 拉取最新镜像
docker pull ghcr.io/je668/chengcheng-learning-workbench:latest

# 运行（映射 3000 端口，持久化数据）
docker run -d -p 3000:3000 \
  -v /path/to/data:/app/data \
  -e CRON_SECRET=your-secret-key \
  chengcheng-learning-workbench:latest
```

镜像大小约 **550MB**（多阶段构建优化，从 1.3GB 降低 60%），使用 zstd 压缩传输。

## 📁 项目结构

```
src/
├── app/
│   ├── (child)/          # 孩子端页面
│   │   ├── home/         # 首页（萌可旋转木马 + 今日引导 + 状态）
│   │   ├── castle/       # 萌可城堡（经营 + 皮肤切换 + 图鉴/商店/背包/成就）
│   │   ├── daily-practice/ # 今日一练（三科打卡，难度递增）
│   │   ├── study/        # 学习模块（拼音/识字/古诗/口算/英语/看图说话）
│   │   ├── games/        # 游戏中心（凑十法/拼音消消乐/识字配对等）
│   │   ├── story/        # 萌可故事（主线9集 + 图鉴远征）
│   │   ├── record/       # 成长记录（日历 + 趋势 + 成长树）
│   │   ├── badges/       # 成就徽章墙
│   │   └── shop/         # 星星币商城（皮肤/头像框/勋章/奖状）
│   ├── (parent)/         # 家长端页面
│   │   ├── dashboard/    # 看板（多娃对比 + 趋势）
│   │   ├── tasks/        # 任务管理
│   │   └── settings/     # 设置（备份/恢复/密码/CSV导出）
│   ├── api/              # 45 条 API 路由
│   └── login/            # 登录页（奇妙萌可主题）
├── components/           # UI 组件
│   ├── MokoCarousel.tsx  # 萌可旋转木马
│   ├── MokoAvatar.tsx    # 萌可头像（支持头像框 + 勋章）
│   ├── ErrorBoundary.tsx # 错误边界
│   └── games/            # 游戏组件
│       └── MakeTen.tsx   # 凑十法/破十法/进位/退位/混合（5关）
└── lib/                  # 核心逻辑
    ├── castle.ts         # 城堡公共 API
    ├── daily-practice.ts # 每日一练（含难度递增）
    ├── moko.ts           # 萌可角色数据 + 商店
    ├── speak.ts          # TTS 三层策略
    ├── study-data.ts     # 2000+ 行学习内容数据
    └── economy.ts        # 经济系统常量
```
