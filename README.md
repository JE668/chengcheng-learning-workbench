# 🏰 程程学习工作台

> **一个让学习像玩游戏一样上瘾的家庭学习平台** —— 基于《奇妙萌可》主题，专为学龄前及小学低年级孩子设计。

---

## 👧 给小朋友：这是你的魔法城堡

你有一座属于自己的**萌可城堡**🏰！城堡里住着你用学习召唤来的萌可小伙伴——爱心萌可、勇气萌可、唱唱萌可……每个萌可都有自己的性格和技能。

### 📝 每天要做三件事

1. **做今日一练** 🎯 —— 语文、数学、英语各 5 道题，答对就能召唤萌可、获得阳光能量和积分
2. **去学习** 📚 —— 学拼音、认字、背古诗、练口算，每完成一个模块就拿到学习星 ⭐
3. **玩游戏** 🎮 —— 拼音拼读、凑十法、古诗填空……得分就是积分！

### 🧸 收集萌可

你可以在「萌可图鉴」里看到所有收集到的萌可，它们住在城堡的不同区域：
- 💖 皇室萌可区（爱心、勇气、唱唱、好奇……）
- 🔐 魔方萌可区（乖乖、仿仿、淘气……）
- 💎 宝石萌可区（发光、钻石、红宝石……）
- 🗝️ 钥匙萌可区（钥匙、锁、宝盒……）
- 🍬 甜心萌可区（甜心、棉花糖、巧克力……）
- ⭐ 闪亮萌可区（流星、星星、彗星……）

### 📖 萌可故事

读萌可的故事，回答小测验，还能**捕捉萌可**回到你的城堡！每个故事章节都藏着新萌可，集齐它们吧！

### 🏰 城堡经营

城堡里的萌可会每天送你**星星币** ⭐，连续打卡天数越多，城堡繁荣度越高，萌可送的币也越多！

用星星币可以去**萌可商店**换城堡皮肤、头像框、奖状……城堡外观也能随你搭配。

### ⚠️ 不打卡会怎样？

如果你有天没完成三科打卡，捣蛋萌可（闹闹、迷糊、淘气）会溜进城堡捣乱！连续多天不打卡，它们会越来越多。

别担心！你可以在**魔法商店**买道具：
- 🧴 **魔法喷雾**（5 阳光）—— 把捣蛋萌可捉回去
- 🛡️ **护盾**（10 阳光）—— 帮萌可挡住一次捣蛋
- 🧊 **冰冻徽章**（8 阳光）—— 保护连胜不中断

### ⏳ 时光沙漏

如果偶尔忘了打卡，可以向爸爸妈妈申请一个**时光沙漏**⏳，回到昨天补打卡。爸爸妈妈审批通过后就能使用。

### 📊 成长记录

在「成长记录」页，你能看到：
- 📅 **打卡日历** —— 像 GitHub 贡献图一样，绿绿的表示坚持了
- 📈 **积分趋势** —— 最近 7 天的积分变化
- 🌳 **成长树** —— 记录你每次的学习和收获

### 🏆 成就徽章

每次学习都能解锁成就：
- 🧸 萌可收藏家 —— 收集更多萌可
- 📅 坚持打卡 —— 连续天数越多越厉害
- 🀄 拼音小将 / ✍️ 识字小能手 / 📜 小诗人 / 🔢 数学小星 / 🗣️ 表达小明星

## 👨‍👩‍👧 给爸爸妈妈：轻松管理孩子的学习

### 🔑 账号体系

- **家长账号**（`parent`）：管理所有孩子、发布任务、审批兑换、查看看板
- **孩子账号**（`cara`）：学习、玩游戏、收集萌可、向家长申请道具

首次启动默认账号：家长 `parent` / `12345678`，孩子 `cara` / `0000`

### 📊 家长看板

在「爸爸妈妈看板」页面，你可以：
- 👀 查看每个孩子的**今日学情**（哪科做了、哪科没做）
- 📈 查看**本周积分趋势图**
- 👨‍👩‍👧 **多娃对比**：如果有多个孩子，自动并列显示积分、萌可数、连胜天数
- 🏰 管理**萌可城堡**：查看城堡状态，给城堡补充资源
- 🎁 审批孩子的**星星币兑换**请求

### 📋 发布任务

在「任务」页面，你可以：
- 发布学习任务（背一首古诗、做一页口算、读一篇课文……）
- 设置任务积分奖励
- 孩子完成后自动发放积分

### ⏳ 时光沙漏审批

孩子请求使用时光沙漏后，你可以在看板或弹窗中看到审批列表。通过后孩子可以回到昨天补打卡。

### 💾 数据备份

在「设置」页面：
- ⬇️ **导出数据** —— 下载 JSON 备份文件
- ⬆️ **导入数据** —— 从备份文件恢复（会覆盖当前数据）
- 🔄 支持修改密码

## 🏗️ 技术栈

| 层面 | 技术 |
|------|------|
| 前端 | Next.js 14 (App Router) + TypeScript + Tailwind CSS |
| 数据库 | Turso (LibSQL) / 本地 SQLite（首次启动自动建库） |
| 认证 | 自定义 session cookie（家长/孩子双角色） |
| 部署 | GitHub Actions → Docker 镜像（GHCR）；支持飞牛 NAS / Vercel |

## 📲 装到主屏（像 App 一样用）

本工作台是 **PWA（渐进式 Web 应用）**：装到主屏后全屏打开，还能离线看已缓存内容。

**安卓**：打开站点 → ⋮ 菜单 →「安装应用」/「添加到主屏幕」

**iPhone / iPad**：Safari → 分享按钮（⬆） →「添加到主屏幕」

> 联网时打开过的页面会被缓存，断网后仍能复习；实时数据需联网同步。

## 🚀 快速开始

```bash
# 1. 克隆仓库
git clone https://github.com/JE668/chengcheng-learning-workbench.git
cd chengcheng-learning-workbench

# 2. 安装依赖
pnpm install

# 3. 启动开发服务器
pnpm dev

# 4. 打开浏览器访问
# http://localhost:3000
```

## 🐳 Docker 部署

```bash
# 拉取镜像
docker pull ghcr.io/je668/chengcheng-learning-workbench:latest

# 运行（映射 3000 端口）
docker run -d -p 3000:3000 \
  -v /path/to/data:/app/data \
  chengcheng-learning-workbench:latest
```

## 🔧 开发命令

| 命令 | 说明 |
|------|------|
| `pnpm dev` | 启动开发服务器（端口 3000） |
| `pnpm build` | 生产构建 |
| `pnpm test` | 运行测试套件（125+ 测试用例） |
| `pnpm seed` | 重置数据库并写入默认账号 |

## 📁 项目结构

```
src/
├── app/
│   ├── (child)/          # 孩子端页面
│   │   ├── home/         # 首页（今日引导 + 状态）
│   │   ├── castle/       # 萌可城堡（经营 + 商店 + 图鉴）
│   │   ├── daily-practice/ # 今日一练（三科打卡）
│   │   ├── study/        # 学习模块（拼音/识字/古诗/口算/英语/看图说话）
│   │   ├── games/        # 游戏中心
│   │   ├── story/        # 萌可故事（阅读 + 捕捉）
│   │   ├── record/       # 成长记录（日历 + 趋势 + 成长树）
│   │   ├── badges/       # 成就徽章墙
│   │   └── shop/         # 星星币商城
│   ├── (parent)/         # 家长端页面
│   │   ├── dashboard/    # 看板（多娃对比 + 趋势）
│   │   ├── tasks/        # 任务管理
│   │   └── settings/     # 设置（备份/恢复 + 密码）
│   ├── api/              # API 路由
│   └── login/            # 登录页（奇妙萌可主题）
├── components/           # UI 组件
└── lib/                  # 核心逻辑
    ├── castle.ts         # 城堡公共 API
    ├── castle-penalty.ts # 逐级惩罚系统
    ├── moko.ts           # 萌可角色数据
    ├── sfx.ts            # Web Audio 音效
    ├── daily-practice.ts # 每日一练逻辑
    └── study-data.ts     # 学习内容数据
```
