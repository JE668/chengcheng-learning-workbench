## 4. 已决定暂不做（附原因，避免后续重复讨论）

| 事项 | 原因 |
|---|---|
| 删除 `Dockerfile` 里的 `COPY /app/node_modules` | 理论上可省数百 MB（standalone 自带 47MB 精简依赖，而整包 node_modules 是 1.0GB），但本地无 Docker 无法验证；**这是收益最大的镜像优化，需在 NAS 上按第 5 节步骤实测后再改** |
| 开启 `PRAGMA foreign_keys=ON` | 会让既有外键约束真正生效，可能使 `/api/parent/reset` 等批量删除路径报错；需先补全删除顺序并加测试 |
| 仓库转 Private / 媒体迁出 git | 用户明确选择保持 public（Actions 配额考虑）。代价：532MB 媒体在每个 clone 里，且家庭媒体公开 |
| Next.js 14 → 15 升级 | 需同步 React 18→19，属独立任务；但 `next` 已有 2 个 critical advisory，**建议排期** |
| framer-motion 从根布局移除（首屏 -64KB gzip） | 会改变「萌可飞行」过场动画观感，属产品决策；技术方案见评审报告（用 CSS 过渡替代，参考算法模块的 `LazyMotion`） |
| 媒体防盗链（Referer 可伪造） | 当前代码已把 `/textbooks`、`/raz` 显式公开（middleware `MEDIA_PREFIXES`），改严会回归「安卓 Edge 视频黑屏」问题；**正确做法是改文档而非改代码** |
| 客户端可伪造积分（game-complete / algorithm-progress / module-progress） | 属真实漏洞但改动面较大（需服务端分值表 + 白名单），列入「下一批」 |
